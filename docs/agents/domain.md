# Domain docs

This repository uses a single context.

- Vocabulary lives in root `CONTEXT.md`.
- Durable architectural decisions live in `docs/adr/`.
- `CONTEXT.md` contains glossary terms only, not implementation details or specifications.
- ADRs record decisions that are difficult to reverse, surprising without context, and based on meaningful trade-offs.
- Agents working in this repository should read the relevant context and ADRs before changing the associated domain.
